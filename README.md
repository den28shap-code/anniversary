# Денис ❤️ Маша — годовщина

Небольшой романтический сайт на Next.js, адаптированный под мобильный Safari.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Где менять текст

Почти весь контент лежит в одном файле:

`data/story.ts`

Там можно быстро заменить даты, фразы, маршруты и финальное приглашение.

## Деплой на Vercel

1. Загрузите папку в GitHub.
2. Импортируйте репозиторий в Vercel.
3. Framework Preset: Next.js.
4. Никаких env-переменных не требуется.

## Что уже есть

- mobile-first дизайн;
- интро про случайно перенесённый рейс;
- история знакомства и отношений;
- Карелия / Москва / Беларусь / Турция;
- повторяющиеся символы ❤️ ♾️ ✈️;
- скрытая пасхалка по 4 тапам на маленькое сердечко;
- финальный вопрос про свидание;
- кнопка «Нет», которая убегает и в итоге исчезает;
- праздничная финальная карточка после «Да».
